# 살도 생활비 내비게이터

## 문제 정의

대부분의 가계부는 지출을 기록한 뒤 숫자를 보여주는 데서 끝납니다. 사용자가 실제로 알고 싶은 것은 “오늘 얼마까지 써도 월말이 무너지지 않는가?”입니다. 계좌 자동연동을 사용하지 않는 살도에서도 기록된 거래와 예산만으로 이 질문에 답할 수 있어야 합니다.

## 제품 목표와 성공 기준

**핵심 약속:** 첫 로그인 후 60초 안에 사용자가 예산이나 첫 거래를 저장하고, 오늘의 안심 사용액을 이해할 수 있게 합니다.

- 첫 화면에서 해야 할 일이 명확하다.
- 기록이 부족하면 숫자를 만들어내지 않고 다음 행동을 안내한다.
- 매일 다시 방문했을 때 합계보다 “오늘의 선택”을 먼저 보여준다.
- 모든 예측에는 기준·신뢰도·참고용이라는 맥락을 함께 표시한다.

운영 단계에서는 첫 기록 완료율, 첫 기록까지 걸린 시간, 내비게이터 재방문율, 오류 발생 후 재시도 성공률을 제품 건강 지표로 삼습니다. 금융 연동 없이도 이 지표를 먼저 검증한 뒤 자동화 기능을 확장합니다.

## 경험 설계 원칙

1. **진짜 데이터만 사용**: 데모용 거래나 계좌 잔액을 운영 화면에 섞지 않습니다.
2. **점진적 공개**: 처음에는 예산·거래·오늘 한도만 보여주고, 분석·CSV·계좌 관리는 필요할 때 엽니다.
3. **한 번에 한 행동**: 온보딩의 세 단계와 모달의 단일 제출 버튼으로 인지 부하를 낮춥니다.
4. **실패도 안내**: 네트워크 오류에는 마지막 확인 시각과 재시도 버튼을 제공하고, 부분적인 계좌 동기화 실패는 계좌별로 설명합니다.
5. **모든 화면 크기에서 동일한 의미**: 모바일 하단 빠른 메뉴와 키보드 포커스, Esc 닫기를 지원합니다.

## 제안 기능

**생활비 내비게이터**는 사용자의 현재 기록을 바탕으로 다음 정보를 제공합니다.

1. 오늘의 안심 사용액: 기준액에서 지금까지 쓴 금액을 빼고 남은 날짜로 나눕니다.
2. 월말 예상 지출: 이번 달 지출 속도를 월 전체로 환산합니다.
3. 상태 신호: 안정권, 주의 필요, 기준 초과, 기록 필요 중 하나로 표시합니다.
4. 가상 지출 실험: 큰 지출을 입력하기 전에 월말 예상 잔액과 남은 하루 한도를 미리 확인합니다.

## 핵심 UI 구조

첫 화면은 사용자의 판단 순서에 맞춰 다음 네 단계로 구성합니다.

1. **오늘의 결정**: 오늘의 안심 사용액을 가장 큰 정보로 먼저 보여줍니다.
2. **바로 행동**: 거래 기록 또는 예산 설정 중 현재 상태에 맞는 행동을 제안합니다.
3. **계산 근거**: 남은 기준액, 월말 예상 지출, 월말 예상 여유와 계산식을 함께 제공합니다.
4. **큰 지출 미리보기**: 5만·10만·30만 원 빠른 선택과 직접 입력으로 결제 전 영향을 확인합니다.

수입·지출 합계와 카테고리 분석은 핵심 결정 다음에 배치합니다. 사용자가 처음 보는 숫자는 과거의 합계가 아니라 오늘의 행동 기준이어야 합니다.

## 계산 원칙

- 기준액은 `설정 예산`을 우선하고, 예산이 없으면 `이번 달 수입`을 사용합니다.
- 기준액이 없을 때는 안심 사용액을 0으로 만들고, 숫자를 추측하지 않습니다.
- 월말 예상 지출은 `현재 월 지출 ÷ 오늘까지 지난 날짜 × 해당 월의 날짜 수`로 계산합니다.
- 이번 달 지출이 없으면 최근 3개월의 월별 지출 평균을 참고값으로 사용합니다.
- 최근 기록 월수가 0/1~2/3 이상이면 예측 신뢰도를 낮음/보통/높음으로 표시합니다.
- 이 기능은 금융상품 추천이나 투자 조언이 아닌, 사용자가 입력한 기록을 정리하는 계획 도구입니다.

## 상태 규칙

| 상태 | 조건 | 사용자 메시지 |
|---|---|---|
| 안정권 | 예상 지출이 기준액 이하 | 현재 속도라면 월말 잔액을 보여줍니다. |
| 주의 필요 | 현재 지출은 기준액 이하이지만 예상 지출이 초과 | 현재 속도를 유지하면 초과할 금액을 보여줍니다. |
| 기준 초과 | 현재 지출이 기준액 이상 | 이미 초과한 금액과 추가 계획 필요 메시지를 보여줍니다. |
| 기록 필요 | 예산과 수입이 모두 없음 | 먼저 기준액을 기록하도록 안내합니다. |

## 구현 범위

- `GET /api/navigator`: 로그인한 사용자의 개인화 계산 결과 반환
- PostgreSQL 집계 쿼리로 현재 월 합계와 최근 3개월 추이 조회
- 대시보드의 안심 사용액 카드와 월말 예상 지출 표시
- 저장되지 않는 금액 슬라이더로 가상 지출 시뮬레이션
- 계산 규칙과 데이터 부족·초과 상태에 대한 단위 테스트
